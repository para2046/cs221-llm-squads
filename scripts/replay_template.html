One model per unit
Each blue unit is controlled by a separate call to the same language model. It sees only what its own unit can see, within sight range, as a short text report.

    
Small action menu
Every step (8 game frames, about 0.5 s of game time) each unit picks one order: stop, move north, south, east or west, or attack an enemy that is inside weapon range.

    
Lock-step, not real time
The game pauses until all units have answered, so model latency never costs game time. The opponent is StarCraft II's own scripted AI.

    
Team reward
The team shares one score: damage dealt and kills, plus a bonus for winning. This score is what reinforcement learning will optimize for the small model.
